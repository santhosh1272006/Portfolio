SKILLS

HTML (HyperText Markup Language) content refers to the text, images, links, and multimedia that make up the structure and substance of a webpage.Most page content is wrapped inside tags to form an HTML element.

CSS (Cascading Style Sheets) is the code used to style a webpage and dictate how HTML elements look to a visitor. While HTML builds the basic structural bones of a site, CSS provides the design, colors, layouts, and fonts.

JS (JavaScript) is a programming language that makes webpages interactive. While HTML builds the page structure and CSS adds the design, JavaScript provides the functionality, logic, and dynamic behavior.

React (often called React.js or ReactJS) is a popular, open-source JavaScript library used for building interactive user interfaces, primarily for single-page web applications.

Node.js (commonly called Node) is an open-source, cross-platform runtime environment that allows you to run JavaScript code on a computer or server, completely outside of a web browser.

MongoDB is an open-source, non-relational database management system designed to store, manage, and process massive volumes of data, it helps to look at its structural building blocks.
